# Contos Mágicos IA Grátis

Versão sem OpenAI API paga.

## Publicação
Envie `app.py`, `requirements.txt` e `packages.txt` para um novo repositório no GitHub.
No Streamlit Community Cloud use Python 3.12, branch `main` e arquivo principal `app.py`.
Não é necessário configurar `OPENAI_API_KEY`.

## Limitações
O roteiro é gerado localmente por regras e as ilustrações são criadas localmente.
A narração usa `edge-tts`, que é gratuita, mas depende de um serviço externo e pode ficar indisponível.
